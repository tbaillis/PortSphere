# PortSphere3D

A WPF desktop application (.NET 8) that displays a spinning 3D green sphere using native WPF 3D (Viewport3D).

## Features
- 3D sphere rendered with Viewport3D
- Texture mapping with selectable grid/octagon grid (XAML DrawingBrush)
- Three point lights: one fixed, two draggable with visible handles
- Real-time texture switching
- Draggable light handles update light positions
- Smooth sphere rotation
- Window size at least 1200x800
- .NET 8+, native WPF 3D only

## Build & Run

```
dotnet build
cd PortSphere3D
 dotnet run
```
